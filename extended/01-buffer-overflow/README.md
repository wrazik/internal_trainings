# Content
This presentation is about buffer overflow attack, including details how to prepare paiload, how to set up environment etc. Raw human-readable slides are available [here](slides/slides.md)

# Running presentation
Presentation was made with reveal.js. To start it on localhost, go into slides and run:
```bash
cd slides
npm install
npx http-server . -p 8000
```
Presentation will be started on http://localhost:8000
